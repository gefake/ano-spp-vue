# АНО СПП

Простой статический сайт на Vue 3 + Vite. Сервер и база данных не нужны.

## Запуск

npm install
npm run dev

## Публикация на Vercel

Загрузите проект в Git-репозиторий и импортируйте в Vercel. Preset: Vite, Build: npm run build, Output: dist. vercel.json обеспечивает прямое открытие страниц.

## Наполнение

src/config.js — платёжная ссылка, VK, документы и реквизиты. Добавьте оригиналы PDF в public/documents и укажите file (например /documents/ustav.pdf). Пока оригиналы не добавлены, страницы предлагают запросить их по email. Юридические тексты не выдуманы.

Для оплаты установите paymentUrl на проверенную ссылку провайдера. До этого доступен перевод по реквизитам. QR со скриншота не использован: его платёжный адрес не подтверждён. Суммы и данные карт сайт не собирает.

Реквизиты перенесены со скриншотов — перед публикацией сверьте их с актуальной карточкой организации.

Фотографии — временные внешние изображения Unsplash; замените URL в src/App.vue и src/style.css на свои файлы из public. Шрифт загружается через Google Fonts с системным запасным вариантом.

Маршруты: /, /documents, /requisites, /support, /regulation, /tax-document, /personal, /oferta, /news. Сохранены старые /page6, /page9, /page10, /payment.

## Изображения и слайдер

Все пути настраиваются в объекте images в src/config.js: hero — фон главного экрана, slides — массив { src, alt }. Для своих файлов создайте public/images и используйте пути /images/photo.jpg. Количество слайдов произвольное. Слайдер поддерживает стрелки, точки, клавиши ←/→ при фокусе и свайпы на телефоне. При одном изображении управление скрывается; пустой массив скрывает слайдер. Автопрокрутка не используется.

Анимации появления и параллакс отключаются при системной настройке уменьшения движения.
